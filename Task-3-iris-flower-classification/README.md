Iris Flower Classification using Machine Learning

Machine Learning project for classifying Iris flower species using flower measurements with Python and Scikit-learn.

1. Project Overview

- This project is a supervised Machine Learning classification project.
- The objective of this project is to predict the species of Iris flowers based on flower measurements.
- The project demonstrates the complete Machine Learning workflow including data analysis, visualization, preprocessing, model training, evaluation, and prediction.

2. Problem Statement

- Predict the species of an Iris flower using Machine Learning based on:
  - Sepal Length
  - Sepal Width
  - Petal Length
  - Petal Width

- The dataset contains three flower species:
  - Iris-setosa
  - Iris-versicolor
  - Iris-virginica
