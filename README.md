Titanic Survival Prediction 🚢

1.Project Overview
This project predicts whether a passenger survived the Titanic disaster using Machine Learning.

2.Dataset
Titanic dataset containing passenger information such as:
- Age
- Gender
- Passenger Class
- Fare
- Embarked Location

3.Machine Learning Models Used
- Logistic Regression
- Decision Tree Classifier
- Random Forest Classifier

4.Best Model
Random Forest achieved the highest accuracy:
~81%

5.Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn

6.Workflow
1. Data Loading
2. Data Cleaning
3. Exploratory Data Analysis
4. Feature Engineering
5. Model Training
6. Model Evaluation
7. Final Prediction System

7.Conclusion
This project demonstrates a complete end-to-end machine learning workflow for beginner-level data science projects.
